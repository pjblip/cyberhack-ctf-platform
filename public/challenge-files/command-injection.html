PING UTILITY

Enter an IP address or hostname to check network connectivity

⚠️ VULNERABLE BACKEND CODE: 
// Python Flask Backend (Vulnerable!)
from flask import Flask, request
import os

@app.route('/ping', methods=['POST'])
def ping():
    target = request.form['target']
    
    # VULNERABLE: Direct command execution without sanitization
    command = f"ping -c 4 {target}"
    result = os.system(command)
    
    return {"output": result}

🎓 What You're Learning:

  • Command Injection: Exploiting unsanitized system command execution
  • Shell Metacharacters: Special characters that chain commands
  • Input Validation: Why user input must be sanitized
  • Principle of Least Privilege: Limiting system command access

💡 Understanding Command Injection:

  • The system executes shell commands directly with user input
  • Shell metacharacters can chain multiple commands together
  • Think about how you can execute additional commands after ping
  • Common separators in shell: ; && || |

🔍 Shell Command Separators:

  • ; - Execute commands sequentially (command1 ; command2)
  • && - Execute next command if previous succeeds
  • || - Execute next command if previous fails
  • | - Pipe output of one command to another
  • ` - Command substitution (backticks)
  • $() - Command substitution (modern syntax)
✅ SECURE CODE (How it should be): 
// Secure version with input validation
import subprocess
import re

@app.route('/ping', methods=['POST'])
def ping():
    target = request.form['target']
    
    # Validate input: only allow alphanumeric, dots, and hyphens
    if not re.match(r'^[a-zA-Z0-9.-]+$', target):
        return {"error": "Invalid target format"}, 400
    
    # Use subprocess with argument list (no shell interpretation)
    try:
        result = subprocess.run(
            ['ping', '-c', '4', target],
            capture_output=True,
            text=True,
            timeout=10,
            shell=False  # IMPORTANT: Prevents shell injection
        )
        return {"output": result.stdout}
    except subprocess.TimeoutExpired:
        return {"error": "Ping timeout"}, 408

🛡️ Security Best Practices:

  • Input Validation: Whitelist allowed characters
  • Avoid Shell=True: Use argument lists instead
  • Least Privilege: Run with minimal permissions
  • Timeouts: Prevent resource exhaustion
  • Logging: Monitor for suspicious activity
