🤖 What is robots.txt?

  • Purpose: Tells search engine crawlers which pages to skip
  • Location: Always at the root — https://example.com/robots.txt
  • Public: Anyone can read it — it is NOT a security control
  • Recon value: Reveals hidden directories that developers don't want indexed

🛡️ Security Lesson:

  • robots.txt only suggests — it does not block access
  • Listing a path in Disallow actually advertises it to attackers
  • Always protect sensitive directories with proper authentication
  • Real pentesters always check robots.txt during reconnaissance
